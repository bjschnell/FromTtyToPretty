# Changelog

All notable changes to FromTtyToPretty will be documented in this file.

Format based on [Conventional Commits](https://www.conventionalcommits.org/).

## [0.1.0] - 2026-03-23

### Features

- Initial release
- Profile-based installation (minimal, desktop, homelab, full)
- Interactive per-script prompting
- Paru AUR helper bootstrap
- Core packages: ghostty, brave, neovim (lazyvim), tailscale
- Hyprland rice: waybar, wofi, dunst, swww, hyprlock, pipewire
- Docker + docker-compose setup
- Homelab essentials: btop, ncdu, lazydocker, eza, fzf, zoxide
- Git bare repo dotfiles management
